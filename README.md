# Sequelize Demo (Практики 1.1 и 1.2)

Предметная область: Автор (Author) и Книги (Book). Связь 1:N.

## Запуск
1. `npm install`
2. `node init.js`

## Файлы
- `database.js` - подключение к SQLite
- `Author.js`, `Book.js` - модели
- `models.js` - связи (hasMany / belongsTo)
- `init.js` - создание, чтение (include) и вывод
